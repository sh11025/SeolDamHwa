CSV 데이터 저장소 (DATA 폴더)

연결 안 됨

상품·주문·주문 상품·지출·상담·재입고·팝업·안내 페이지·매장 설정·사진을 표 하나 = CSV 파일 하나로 프로젝트의 DATA 폴더에 저장해요. 엑셀로 열어 볼 수 있고, 나중에 서버 데이터베이스로 옮길 때 그대로 표로 쓰면 돼요. 표 구조는 DATA/README.md에 있어요.

이 브라우저는 폴더에 바로 저장할 수 없어서 파일로 내려받아요. 크롬·엣지에서는 폴더에 바로 저장돼요.

예시 데이터

버튼 한 번이면 연습용 데이터가 한꺼번에 들어가요: 꽃다발·꽃바구니·화분·정기 배송·상담 상품까지 예시 상품 8개(1만9천원~25만원, 품절·품절 임박 포함), 최근 90일 주문, 석 달치 지출, 상담 문의 3건. 이름 앞에 [예시]가 붙어요.

백업·복원

상품, 주문, 지출, 상담, 매장 설정, 팝업을 파일 하나로 내려받아 두세요. 브라우저 기록을 지워도 이 파일로 되살릴 수 있어요. (AI 키와 디스코드 주소는 백업에 넣지 않아요.)

디스코드 알림

디스코드에서 채널 2개(예: #주문, #상담)를 만들고, 각 채널의 설정 → 연동 → 웹후크에서 만든 주소를 붙여 넣으세요. 알림에는 연락처와 주소를 넣지 않아요. 지금은 이 컴퓨터에서 들어온 주문·상담만 알림이 가요(서버 연결 후 모든 손님 주문으로 넓어져요).

기본 AI

• 사용하는 곳: 상품 등록 창의 [✨ AI로 문구 초안]
• 모델 이름은 비워 두면 기본값을 써요. 새 모델이 나오면 각 회사 사이트에서 이름을 확인해 바꿔 넣으세요.
• 키는 관리자 화면에서만 쓰고, 손님 화면이나 백업 파일에는 들어가지 않아요.
