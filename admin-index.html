CSV 데이터 저장소 (DATA 폴더)

연결 안 됨

상품·주문·주문 상품·지출·상담·재입고·팝업·안내 페이지·매장 설정·사진을 표 하나 = CSV 파일 하나로 프로젝트의 DATA 폴더에 저장해요. 엑셀로 열어 볼 수 있고, 나중에 서버 데이터베이스로 옮길 때 그대로 표로 쓰면 돼요. 표 구조는 DATA/README.md에 있어요.

이 브라우저는 폴더에 바로 저장할 수 없어서 파일로 내려받아요. 크롬·엣지에서는 폴더에 바로 저장돼요.

백업·복원

상품, 주문, 지출, 상담, 매장 설정, 팝업을 파일 하나로 내려받아 두세요. 브라우저 기록을 지워도 이 파일로 되살릴 수 있어요. (AI 키와 디스코드 주소는 백업에 넣지 않아요.)

💡 데이터 안전 안내

서버 모드에서는 정리 작업을 실행하기 직전 자동으로 서버 백업을 생성하므로 필요한 경우 [서버 백업]에서 복원할 수 있습니다. 단, 정리 실행 이전에 생성된 이전 서버 백업 파일이나 사장님이 PC에 다운로드해 둔 백업 파일에는 과거 개인정보가 남아 있을 수 있습니다.

Supabase Storage 연결

외부 비공개 버킷(Private Bucket)에 원본 사진을 백업해요. 서비스 롤 키(Service Role Key)는 서버 파일(DATA/.supabase.json)에만 저장되고 외부에 절대 노출되지 않아요.

※ 보안을 위해 한 번 저장된 키는 브라우저로 다시 전달되지 않으며 화면에 표시되지 않습니다.

초보 사장님을 위한 설담화 관리자 센터 사용 설명서

코딩을 모르셔도 매일 매장을 쉽고 편안하게 운영하실 수 있도록 안내해 드려요.

운영 가이드 목차

1장

⏰ 매일의 매장 운영 3단계 루틴

출근해서 퇴근할 때까지 관리자 센터를 어떻게 쓰는지 순서대로 따라해보세요.

1단계. 아침 출근 (현황 파악)

• 관리자 센터 상단 바를 보시면 "⏰ 오늘 출고 N건"과 "💬 상담 N건"이 한눈에 보입니다.

• 대시보드 화면 바로 아래에 있는 [오늘의 출고·제작 원스톱 퀵패널]에서 오늘 나갈 꽃다발과 시간을 빠르게 확인합니다.

2단계. 낮 작업 시간 (꽃 만들기 & 포장)

• 주문 관리 탭의 [⏰ 오늘 제작·출고 시간표] 뷰를 열어두고 작업합니다.

• 오전(10~13시), 오후(14~18시), 저녁(18~21시) 시간대별로 카드 메시지와 실크 보자기 포장 여부를 확인하며 꽃을 제작합니다.

• 포장이 끝난 꽃다발은 카드 우측 상단의 [🌸 제작 완료] 버튼을 콕 누르면 초록색 [✅ 포장 완료]로 바뀌어 누락을 방지합니다.

3단계. 오후 출고 및 퇴근 (알림 발송 & 정산)

• 택배 주문은 [송장 일괄 입력] 도구로 한 번에 송장을 넣고 '배송 중'으로 변경합니다.

• 매장 픽업 손님에게는 주문 상세의 [🏪 픽업 준비완료 안내] 버튼을 눌러 문자 앱으로 완성 알림을 보냅니다.

• 퇴근 전 '매출·지출 관리' 탭에서 오늘 발생한 꽃 사입비나 부자재 지출을 한 줄 적어두면 순이익이 자동 계산됩니다.

2장

📋 오늘 제작 시간표 보드 활용법

스마트폰이나 태블릿을 작업대에 올려두고 종이 출력 없이 꽃을 만드는 방법입니다.

• 어디서 보나요? 관리자 센터 상단에서 [주문 및 배송 관리]로 이동한 뒤, [⏰ 오늘 제작·출고 시간표] 버튼을 누르시면 됩니다.

• 시간대별 자동 정돈: 손님이 요청하신 희망 시간에 따라 오전 / 오후 / 저녁 / 택배(시간 미지정) 4개 영역으로 주문 카드가 자동 분류됩니다.

• 보자기 포장 강조: 손님이 전통 실크 보자기 포장을 신청하신 경우, 노란색 [🎀 실크 보자기 & 노리개 포장] 뱃지가 눈에 띄게 강조되어 포장 실수를 예방합니다.

• 카드 메시지 확인: 카드의 붉은색 따옴표 칸에 손님이 적으신 카드 문구가 바로 보여, 꽃을 꽂으면서 편지 카드를 바로 작성하실 수 있습니다.

• 제작 완료 체크: 제작이 끝난 주문의 [🌸 제작 완료]를 누르면 포장 완료 상태로 변경되며 카드가 차분한 톤으로 바뀌어 남은 작업만 또렷이 보입니다.

3장

🌸 '이달의 추천 꽃' & 상품 관리 가이드

쇼핑몰 첫 화면 메인 버튼에 띄울 대표 꽃을 마음대로 바꾸는 방법입니다.

Q. 쇼핑몰 첫 화면의 [이달의 추천 : ○○○ 보기] 버튼은 어디서 바꾸나요?

1. [상품 및 한 줄 글귀 관리] 탭으로 이동합니다.

2. 상품 목록 맨 위에 있는 [🌸 쇼핑몰 메인 '이달의 추천 꽃'] 카드를 봅니다.

3. [🎨 사진 보며 추천 꽃 고르기] 버튼을 누르면 전체 꽃 사진이 바둑판처럼 펼쳐집니다.

4. 원하는 꽃 카드의 [이 꽃으로 추천 변경하기] 버튼을 누르면 즉시 손님 화면에 반영됩니다!

꽃 상품 재고와 품절 관리

• 품절 처리: 꽃 시장에서 특정 꽃이 수급되지 않을 때는 상품 목록에서 수량을 0으로 줄이시면 쇼핑몰에 자동으로 '일시 품절' 표시가 뜨고 주문이 막힙니다.

• 재입고 알림 손님: 재고가 0이었다가 숫자를 올리면 "이 상품을 기다리는 손님이 N명 있어요" 알림이 뜨며, 바로 연락처를 확인하실 수 있습니다.

4장

🚚 배송·픽업 알림 문자 & 운송장 일괄 처리

손님에게 친절한 문자를 원클릭으로 보내고, 여러 건의 송장번호를 빠르게 넣는 방법입니다.

🏪 매장 픽업 손님 준비완료 문자 보내기

1. 주문 목록에서 해당 픽업 주문의 줄을 눌러 상세 정보를 펼칩니다.

2. [🏪 픽업 준비완료 안내] 버튼을 누르면 정중한 완성 안내 문구가 펼쳐집니다.

3. [문자 앱 열기]를 누르면 스마트폰의 문자 앱이 열리면서 손님의 전화번호와 문구가 자동 세팅되어 [전송]만 누르시면 됩니다. (PC에서는 [문구 복사] 가능)

📦 여러 주문 운송장 번호 한 번에 넣기

1. 오늘 발송할 택배 주문들의 앞쪽 체크박스를 여러 개 체크합니다.

2. 표 위에 나타나는 노란색 툴바에서 [📦 송장 일괄 입력] 버튼을 누릅니다.

3. 택배사(예: CJ대한통운)를 일괄 지정하고 송장번호를 순서대로 적은 뒤 [일괄 저장하기]를 누르면 모두 자동으로 '배송 중'으로 바뀝니다.

5장

📅 쉬는 날(임시 휴무) 달력에서 지정하는 법

명절, 집안 행사, 매장 공사 등으로 특정 날짜에 주문을 받지 않는 방법입니다.

• 어디서 설정하나요? [매장 정보 설정] > [공휴일·임시 휴무] 탭으로 이동합니다.

• 달력에서 콕 찍기: 상단에 나오는 '달력에서 쉬는 날 콕 찍기' 화면에서 쉬고 싶은 날짜(흰색 칸)를 클릭합니다.

• 사유 입력: 팝업창에 '추석 연휴', '개인 사정' 등 사유를 적고 확인을 누르면 빨간색으로 바뀌면서 휴무일로 등록됩니다.

• 효과: 사장님이 휴무로 지정하신 날짜는 쇼핑몰 손님의 배송 희망일 달력에서 자동으로 선택이 불가능해져서 당황스러운 주문을 사전에 차단합니다.

• 취소하기: 빨간색으로 표시된 날짜를 다시 클릭하시면 "임시 휴무를 해제할까요?" 묻고 정상 영업일로 되돌아옵니다.

💡 단골 손님 관리 & 유용한 꿀팁

🌸 단골 손님 뱃지 활용법

• 손님이 과거에 주문했던 전화번호로 다시 주문하면, 주문 목록과 시간표에 자동으로 [🌸 단골 · 2회차 (총 18만원)] 뱃지가 뜹니다.

• 단골 손님께는 꽃을 만드실 때 한 송이 더 풍성하게 넣어드리거나, 작은 노리개 사은품을 동봉해 드리면 손님의 감동과 재구매율이 크게 높아집니다.

• 주문 상세 아래쪽의 [📝 사장님 비공개 메모]에 "단골 사은품 노리개 동봉함"이라고 적어두시면 사장님만 보실 수 있습니다.

🔍 키보드 빠른 검색 (Ctrl + K)

• 컴퓨터에서 일하시다가 키보드의 Ctrl 키와 K 키를 동시에 누르시면 언제든 검색창이 뜹니다.

• 손님 이름이나 전화번호 뒷자리만 치시면 해당 주문을 1초 만에 찾아 바로 펼쳐줍니다.

🔔 새 주문 소리 알림 켜두기

• 상단 헤더의 [🔔 새 주문 소리 켜짐] 버튼을 켜두시면 다른 탭을 보거나 매장에서 음악을 틀어두어도 새 주문이 들어올 때 은은한 종소리가 울립니다.
