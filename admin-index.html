백업·복원

상품, 주문, 지출, 상담, 매장 설정, 팝업을 파일 하나로 내려받아 두세요. 브라우저 기록을 지워도 이 파일로 되살릴 수 있어요. (AI 키와 디스코드 주소는 백업에 넣지 않아요.)

디스코드 알림

디스코드에서 채널 2개(예: #주문, #상담)를 만들고, 각 채널의 설정 → 연동 → 웹후크에서 만든 주소를 붙여 넣으세요. 알림에는 연락처와 주소를 넣지 않아요. 지금은 이 컴퓨터에서 들어온 주문·상담만 알림이 가요(서버 연결 후 모든 손님 주문으로 넓어져요).

AI 도우미 (Claude · GPT · Gemini)

상품 글귀·꽃말·설명 초안과 상담 답변 초안을 써 줘요. 쓰시는 AI의 키를 넣고, 기본으로 쓸 AI를 고르세요. 초안을 만들 때 다른 AI로 바꿀 수도 있어요. 사용한 만큼 각 회사 요금이 나가요.

기본 AI

• 사용하는 곳: 상품 등록 창의 [✨ AI로 문구 초안], 상담 문의의 [✨ AI 답변 초안]
• 모델 이름은 비워 두면 기본값을 써요. 새 모델이 나오면 각 회사 사이트에서 이름을 확인해 바꿔 넣으세요.
• 키는 관리자 화면에서만 쓰고, 손님 화면이나 백업 파일에는 들어가지 않아요.
