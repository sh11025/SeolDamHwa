## [63] 중복 주문 막기·겹치지 않는 주문 번호·입력값 확인 (14:24)
- 주문하기 버튼을 빠르게 여러 번 눌러도 주문이 한 번만 들어가고, 주문 처리 중에는 버튼에 '주문 접수 중…'이 표시돼요.
- 주문 번호가 날짜와 영어·숫자 조합(SDH-YYMMDD-XXXX)으로 만들어져 같은 시각에 여러 손님이 주문해도 번호가 겹치지 않아요.
- 상품 가격이나 재고에 잘못된 글자가 들어가거나 연락처 자릿수가 맞지 않으면 바로 안내하고 저장을 막아 줘요.
확인: 주문하기 연타 시 주문 1건 접수 / 잘못된 번호 입력 시 안내 확인 / 관리자 상품·지출·쿠폰 입력값 검증
