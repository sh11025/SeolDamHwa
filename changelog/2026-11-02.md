# 2026-11-02 변경 기록

## [45] 오프라인 쿠폰 (09:50)
- 관리자에 '오프라인 쿠폰' 탭이 생겼어요. 이름·할인(금액 또는 %)·최소 주문 금액·기간·장수를 정하면 장마다 다른 코드가 생기고, [인쇄]로 A4 한 장에 8장씩 코드+QR 카드를 뽑을 수 있어요.
- 손님은 결제 ③ 단계에서 코드를 넣거나 QR로 들어와 할인을 받고, 한 장은 한 번만 쓸 수 있어요(상품 금액에만 할인, 배송비 제외). 주문 기록에 쿠폰과 할인 금액이 남아요.
- 묶음마다 몇 장 썼는지 보이고, [멈추기]로 잠깐 막을 수 있어요. 쿠폰에는 손님 정보를 저장하지 않아요.
확인: 관리자 '오프라인 쿠폰'에서 1장 만들기 → 쇼핑몰 결제 ③에 코드 입력

## [44] DATA 폴더 CSV가 진짜 저장소로 (서버 연결 1단계) (09:20)
- `start-server.bat`을 더블클릭해 열면 쇼핑몰·관리자에서 바뀐 내용(상품·재고·주문·상담·꽃 사전 등)이 바로 DATA 폴더 CSV에 저장되고, 다른 탭·기기의 변경도 20초마다 받아 와요.
- 10분마다 자동 백업(DATA/backup)을 남기고, 처음 연결할 때 브라우저 데이터와 DATA 폴더 중 무엇을 쓸지 물어봐요.
- 같은 와이파이 휴대폰(손님)은 개인정보 표를 볼 수 없고 새 주문 추가·재고 줄이기만 할 수 있어요. 인터넷 공개는 로그인·호스팅 뒤에.
확인: start-server.bat 실행 → 관리자 왼쪽 아래 '● DATA 폴더에 저장됨'
